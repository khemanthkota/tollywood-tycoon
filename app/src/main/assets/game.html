Connect to TV

Available now: Mirror your phone screen to a compatible TV or casting receiver using Android screen casting or a wired display connection. Open Audience display and keep it visible while mirroring.

Hybrid connection plan: Phase 1: same-Wi-Fi pairing without internet, using a QR code or six-digit room code and a local synchronization service. Phase 2: optional internet-based rooms for remote viewers. Multiple TV, tablet, and phone viewers can join the same room simultaneously without accounts. All audience devices are read-only; organizer controls remain on the host device. Live audience rooms are session-only: closing the organizer app ends the room and invalidates its pairing code. Existing local saved-game functionality remains separate; reopening a saved game does not automatically restore the old audience room. If a viewer disconnects, the planned viewer client will retry automatically and restore the latest auction snapshot; if reconnection fails, it will offer QR or six-digit code pairing again. Viewer disconnects must never pause the organizer game. If the organizer disconnects, the planned room service will pause auction timing and preserve bids; the original organizer may resume after reconnecting, or an explicitly authorized backup may take over. Exactly one organizer can control the room at a time. Planned backup access: the primary organizer pre-approves a trusted backup device before gameplay; a separate emergency recovery PIN can authorize takeover if the primary device is unavailable. The recovery PIN must not be the public six-digit audience room code. The room service must revoke the former controller before activating the replacement. Backup authorization and takeover are not available in this build.

Final results

One director and at least one actor and actress are required per movie. You may select several actors and actresses owned by that player. Each auction contract can be used in only one movie. A person may appear in different movies through separately won contracts. Production spending must be at least 30% of cast bids and fit within your remaining ₹100 Cr player budget. Production above ₹25 Cr does not increase game collections. Mix & Match merges the six industry pools, with each person listed once per role. Some artists work in more than one industry. Fictional director strength and shared genre traits raise returns. Game ROI = (game box office value − cast bids − production) / total investment. All industries use the same fictional ₹100 Cr game economy, including Hollywood. Ratings, genre traits and returns are designed game attributes, not real-world talent rankings, historical collections or producer receipts. Classic and contemporary artists are included. Progress saves separately for each industry. Data saves on this device.
